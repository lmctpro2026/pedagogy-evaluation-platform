Sprint 3 Review01
What we were asked to build

Four requirements.

R1Ask participants, after the survey, whether they will provide demographic information. If yes, collect age group, gender and academic level A–E, linked to the same survey response.
R2Focus the sprint on the admin dashboard: participants, started, completed, accounts created, a TP / PD / TA / TPP summary, and demographic charts.
R3Participants cannot submit unless every question is answered, an error is shown when incomplete, and results save only on completion.
R4Verify all of the above by testing.

Summary03
R3 · Validation

Nothing partial gets saved.

  • At each question — clicking Next without an answer shows an explicit message, instead of a silently disabled button
  • At submission — a review screen lists all 20 answers by category; submitting while incomplete names the exact questions missing
  • One gate — no score is calculated, stored or emailed until all 20 questions hold a valid answer

Demographics06
R1 · Demographics

Linked to the response, not the person.

  • Joined by session — demographics attach to the same record as the scores, which is exactly what the requirement asked for
  • Declines are recorded too — otherwise “85% opted in” would be unmeasurable; we could not tell a decline from never being asked
  • Write-once — no update or delete permission exists, so knowing a session ID does not let anyone alter someone's answers
  • Anonymous participants included — no account needed to contribute

R2 · Dashboard

Categories and demographics.

  • TP / PD / TA / TPP — the bar chart now sits above a table giving responses, mean, median, lowest and highest per category
  • Both read the same sessions — so the chart and the table can never disagree with each other

Quality assurance

Four defects found before testing.

1Save failures reported as successes. The database client reports errors by return value, not by throwing. A rejected write passed unnoticed and the participant was told it saved.
2Navigating away cancelled the save. Buttons are now held until the write confirms, capped at six seconds.
3Errors attached to the wrong question. Two panels coexist during the slide animation.
4Review returned you to question 20. Rather than to where you left off.

R4 · Testing

What we verified.

  • Degraded mode — loads and explains, never breaks
